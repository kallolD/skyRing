This directory contains notebooks to run the FIXED-SKY analysis.

To analyze GW250114, use the `GW250114-fixed-sky.ipynb` notebook.

To analyze GW190521, use the `GW190521-fixed-sky.ipynb` notebook.

To see how posteriors change with different starting times, use the `GW250114-fixed-sky-tM-shifts.ipynb` and `GW190521-fixed-sky-tM-shifts.ipynb` for GW250114 and GW190521 respectively.
