This directory contains notebooks to run the FULL-SKY analysis.

To analyze GW250114, use the `GW250114-full-sky.ipynb` notebook.

To analyze GW190521, use the `GW190521-full-sky.ipynb` notebook.

To see how posteriors change with different starting times, use the `GW250114-full-sky-tM-shifts.ipynb` and `GW190521-full-sky-tM-shifts.ipynb` for GW250114 and GW190521 respectively.
