This directory contains notebooks to simulate and analyze a ringdown injection with $(2,2,1)+(2,2,0)$ modes.

To simulate the signal, use the `noiseless-sim.ipynb` notebook. The source parameters can be set inside the notebook itself.

`noiseless-sim-full-sky.ipynb` analyzes the injection using the FULL-SKY approach.

`noiseless-sim-fixed-sky.ipynb` analyzes the injection using the FIXED-SKY approach.
